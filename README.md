# ISLP PDF to EPUB

Converts `ISLP_website.pdf` (*An Introduction to Statistical Learning with Applications in
Python*) into a reflowable EPUB 3 tuned for the Kobo Libra 2.

For educational and experimental use only. No commercial use.

- `src/` — pipeline code
- `work/` — intermediate artefacts (not committed)
- `output/` — the finished EPUB
- `journal/JOURNAL.md` — what was tried, what worked, what failed
- `index.html` — visual story of the attempts

## Setup

```bash
uv sync
npm install
```
